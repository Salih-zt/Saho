# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-25

### Added
- **Core Core Shell**: Created a unified Single Page Application (SPA) container inside `src/app/page.tsx` for instantaneous tab switching without network delays.
- **SAHO NOW**: Pulsating speech-to-text trigger integrated with native browser Web Speech API.
- **Guided Breathing**: Frame Motion scale breathing visualizer utilizing the 4s:4s:4s:4s breathing cycle with reduced motion settings checks.
- **Caregiver Mode**: Added large-typography teleprompter scripts covering Overdose, Panic, Aggressive Behaviour, Withdrawal, and Craving emergencies with built-in voice narration.
- **Trigger Vision & Drug ID**: Integrated canvas-based camera snapshot scanner with base64 size checks and custom warning banners.
- **Circle of Safety**: Added configurable trusted contacts editor (max 5 contacts) and SMS alert dispatcher mockup.
- **Recovery Timeline**: Created an anxiety-free progress list celebrating positive recovery milestones instead of streak counters.
- **Education Hub**: Created a learning material repository covering detoxification, Naloxone protocols, and safe prescriptions.
- **Settings Accessibility Options**: Integrated toggles for High Contrast, Large Fonts, and Reduced Motion.
- **Testing Architecture**: Set up Vitest configuration with JSDOM and mocked Web Speech API specs, adding unit test suites.
